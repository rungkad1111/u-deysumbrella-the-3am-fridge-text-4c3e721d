The one line a smart fridge would text its owner at 3am.

## The line

> 3am. Fourth visit tonight. I contain nothing new. I never did. Go to bed.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (73 characters, within the 140-character cap).
Node 22+, standard library only.
